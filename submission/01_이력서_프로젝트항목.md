# 이력서 — 프로젝트 항목 (추가분)

**EngineSquare 통합 보안 관제·SOAR 자동 대응 시스템** (SKT ALEPH 1기 팀 프로젝트, 3인 / 팀장)
- 기간: 2026.__ ~ 2026.11 (※ 시작일은 활동일지 기준으로 확인해 기입)
- 역할: 팀장 · 시나리오 3(킬체인 상관분석·IoT 대응) 설계·구현 전담, 통합 보고서·발표 자료 취합
- 사용 기술: Graylog 6.1, n8n, pfSense, Wazuh, Flask·MySQL, ESP32-C3(MicroPython), Docker, Python
- 핵심 성과
  - 같은 IP에서 정찰·인증 공격·장치 제어 **3종이 10분 내 모이면 CRITICAL**, 2종이면 WARNING으로 분리하는 상관분석 규칙 설계 → 정찰·침투·장치 제어 전 구간 **무인 자동 대응**(pfSense 차단 표 0→1건, ESP32 Lockdown, 티켓 `INC-KILLCHAIN-003`, 디스코드 알림) 시연 검증
  - 오탐 방지: 2종만 발생 시 CRITICAL 미격상(노랑 경고만) 검증
  - n8n→pfSense SSH 타임아웃을 계층별 배제로 원인 특정(ssh2 알고리즘 협상) → Ed25519 키 인증으로 해결
  - 설정·워크플로 JSON·콘텐츠 팩·펌웨어를 GitHub에 정리, 새 PC 설치 가이드와 단위 테스트 7건(통과) 구비
- 링크: https://github.com/gamedh823-cmd/network-team03

> 위 수치 중 "3종/10분/0→1건/INC-KILLCHAIN-003/7건"만 기록으로 확인된 값입니다. 체인 완성 소요 시간(초)은 아직 측정 기록이 없어 넣지 않았습니다 — 측정 후 한 줄 추가하면 가장 강한 수치가 됩니다(reproduction-guide 9절).
