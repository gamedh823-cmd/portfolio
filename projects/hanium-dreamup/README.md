# 한이음 드림업 프로젝트 — 생성형 이미지 AI 기반 결함 데이터 증강 시스템

**소속 / 기간** 2025 한이음 드림업 프로젝트 (과학기술정보통신부 주최, 2025.04~2025.10, 팀 "genboost")
**최종 성과** 완성도 높은 시스템 구현으로 장려상 수상
**사용 기술** Python, Django, AWS EC2/S3, Stable Diffusion v1.5, ControlNet, LoRA

## 문제
제조 현장에서 결함 이미지를 학습 데이터로 쓰려면 실제 불량이 나야만 모이는데, 불량 발생 빈도가 낮아 데이터를 충분히 모으기 어려웠습니다.

## 나의 역할
AI 모델 개발 파트를 맡았고, 요구사항 정의서·서비스 흐름도·화면 설계서·알고리즘 명세서·ERD까지 설계 문서 작업도 같이 했습니다.

## 구현 방법
- Stable Diffusion v1.5에 ControlNet(결함 마스크로 위치·형상 제어)과 LoRA(제조 도메인 결함 질감에 파인튜닝, Rank 4~16)를 결합해, 정상 이미지 + 결함 마스크 + 텍스트 프롬프트(예: `switch contamination defect`)를 입력하면 결함이 반영된 NG 이미지를 합성하는 파이프라인을 만들었습니다.
- Django 백엔드로 웹 UI를 만들어 정상 이미지·마스크·프롬프트를 업로드하면 바로 결함 이미지를 생성·다운로드할 수 있게 했고, AWS EC2(GPU)에서 학습·추론을, S3에 데이터를 저장했습니다.
- FP16, 8bit AdamW, xFormers attention 등으로 GPU 메모리 사용량을 줄이고 학습 속도를 높였습니다.

## 문제 해결 과정
가장 컸던 문제는 초기 학습 방식이 확산 모델의 표준 방식과 어긋나 있었던 것입니다. 처음엔 정상 이미지에 노이즈를 주입하고 결함 이미지 자체를 복원하도록 학습시켰는데, 이러면 결함이 이미지에 희미하게만 반영됐습니다. 학습 목표를 "결함 이미지에 노이즈를 주입하고 그 노이즈를 예측하는" 표준 DDPM 방식으로 교정하고서야 결함이 뚜렷하게 반영되기 시작했습니다. 그 외에도 DataLoader의 worker 수를 늘렸다가 시스템 RAM이 한계에 도달해 OOM이 나는 문제가 있었는데, worker 수와 prefetch factor를 줄이고 pin_memory를 켜는 식으로 해결했습니다. 또한 처음엔 Diffusion 모델을 처음부터 직접 학습하려 했지만 GPU 자원이 부족해서, 사전학습된 Stable Diffusion을 기반으로 필요한 부분만 파인튜닝하는 방향으로 전략을 바꿨습니다.

## 결과
완성도 높은 시스템 구현으로 장려상을 받았습니다.
