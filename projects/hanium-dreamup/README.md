# 한이음 드림업 프로젝트 — 생성형 이미지 AI 기반 결함 데이터 증강 시스템

**소속 / 기간** 한이음 드림업 프로젝트
**최종 성과** 완성도 높은 시스템 구현으로 장려상 수상
**사용 기술** Python, Django, AWS S3/RDS, Stable Diffusion, ControlNet, LoRA

## 문제
제조 현장에서 결함 검사 모델을 학습시키기에 충분한 결함 이미지 데이터가 부족했습니다. 실제 결함 발생을 기다려 데이터를 모으기에는 시간과 비용이 크다는 문제가 있었습니다.

## 나의 역할
AI 모델 개발 파트를 주도했습니다. 또한 요구사항 정의서, 서비스 흐름도, 화면 설계서, 알고리즘 명세서, ERD 설계 등 프로젝트 전반의 문서화를 체계적으로 수행했습니다.

## 구현 방법
- Stable Diffusion, ControlNet, LoRA를 활용해 제조 결함 이미지를 생성하는 생성형 이미지 AI 모델 개발
- Django 기반 백엔드와 AWS S3/RDS를 연동하여 생성된 데이터가 실제 서비스에 반영되도록 구성
- 요구사항 정의서 → ERD → 화면 설계서 → 알고리즘 명세서 순으로 설계 문서를 체계화

## 문제 해결 과정
AI 모델 산출물이 실무 응용 소프트웨어와 안정적으로 연동되지 않는 문제를 서비스 흐름도와 알고리즘 명세서를 기준으로 인터페이스를 재정의하여 해결했습니다.

## 결과
완성도 높은 시스템 구현으로 장려상을 수상했습니다.
