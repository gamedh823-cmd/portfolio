# 생성형 AI 기반 이상 탐지 모델 설계

**소속 / 기간** 인공신경망(ANN) 프로젝트
**최종 성과** 학습 데이터 재구성 오차율 최소화 달성
**사용 기술** PyTorch, Autoencoder, Diffusion Model

## 문제
미세한 변칙 패턴까지 정확하게 잡아내는 이상 탐지는 정상 데이터의 특징을 얼마나 정밀하게 학습하느냐에 성능이 좌우됩니다. 단일 구조(Autoencoder만, 또는 Diffusion만)로는 정상 패턴 학습과 미세 변칙 포착 사이의 균형을 맞추기 어려웠습니다.

## 나의 역할
Autoencoder와 Diffusion 모델을 융합한 이상 탐지 알고리즘을 설계하고, PyTorch로 직접 구현 및 네트워크 최적화를 수행했습니다.

## 구현 방법
- Autoencoder 구조로 정상 데이터의 잠재 특징을 학습
- Diffusion 모델을 결합해 재구성 과정에서 미세한 변칙 패턴에 대한 민감도를 높임
- 재구성 오차(reconstruction error)를 이상 탐지 스코어로 사용

## 문제 해결 과정
재구성 오차율이 기대만큼 낮아지지 않는 구간에서 네트워크 구조와 하이퍼파라미터를 반복 조정하며 정상 데이터 학습 효율을 개선했습니다.

## 결과
학습 데이터에 대한 재구성 오차율을 최소화하는 수준까지 모델을 최적화했습니다.
