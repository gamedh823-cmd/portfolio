# 의미론적 검색 엔진 모델 구축 — "4bit Pathfinder"

**소속 / 기간** 2025 SSU 데이터톤 대회 (팀 "4bit")
**최종 성과** 대회 우수상 수상
**사용 기술** Python, FAISS, ko-sroberta-multitask (Sentence-Transformers), Streamlit

## 문제
62,199건의 공학 분야 논문 메타데이터[^meta](DBpia, 2021~2025)를 다뤘는데, 트렌드 분석에 가장 중요한 키워드(KYWD) 필드가 **26.38%나 비어 있었습니다.** 이 상태로는 정확한 연구 동향 분석이 불가능했고, 설령 키워드가 있어도 사용자가 입력한 검색어와 논문 제목의 단어가 정확히 일치하지 않으면 관련 논문을 못 찾는 문제도 있었습니다.

## 나의 역할
데이터 전처리[^prep]부터 모델링 및 최적화까지 이 파트를 맡았습니다.

## 구현 방법
- 결측치[^nan]를 그냥 버리지 않고, 논문 제목에서 단어를 추출해 채우는 방식을 택했습니다. 긴 단어부터 우선 매칭되도록 정렬한 `master_vocab` 사전을 만들고, 동의어(예: "딥러닝"·"deep learning"·"Deep Learning")를 하나로 묶는 매핑과 140여 개 불용어[^stop] 사전으로 노이즈[^noise]를 걸러 제목에서 키워드를 역추출[^rev]했습니다.
- 논문 제목을 `ko-sroberta-multitask`[^ko]로 임베딩[^emb]하고 FAISS[^faiss] 인덱스에 넣어, 62,199건 전체를 실시간으로 유사도 검색[^sim]할 수 있게 만들었습니다.
- Streamlit[^st]으로 "4bit Pathfinder"라는 대화형 웹 UI를 만들어, 키워드를 입력하면 관련 연구 분야·핵심 연구자·주요 기관을 바로 보여주도록 구성했습니다.

## 문제 해결 과정
키워드 결측치 26.38%를 제목 기반 역추출로 복구했더니 **77.39%가 복구되어 최종 데이터 충전율[^fill] 94.0%**를 달성했습니다. 검색 결과에는 "소개", "안내", "공지" 같은 연구와 무관한 행정성 노이즈가 섞여 들어오는 문제도 있었는데, 이런 단어가 포함된 항목을 걸러내는 필터링 로직을 추가해서 순수 연구물 위주로 결과가 나오도록 정리했습니다.

## 결과
결과적으로 데이터톤[^datathon]에서 우수상을 받았습니다.

## 용어 설명

비전공자도 읽을 수 있도록, 본문에 나온 용어를 풀어 적었습니다.

[^meta]: **메타데이터** — 데이터를 설명하는 데이터. 여기서는 논문 본문이 아니라 제목·저자·키워드·발행연도 같은 논문 정보를 뜻해요.
[^prep]: **전처리** — 분석이나 AI 학습 전에 데이터를 쓸 수 있게 정리하는 작업이에요. 빈칸 채우기, 중복 제거, 형식 통일 등을 해요.
[^nan]: **결측치** — 표에서 비어 있는 칸. 값이 입력되지 않아 빠진 데이터예요.
[^stop]: **불용어** — 분석에서 의미가 없어 제외하는 단어예요. 예: '소개', '안내', 조사.
[^rev]: **역추출** — 이미 있는 글(여기서는 논문 제목)에서 거꾸로 필요한 정보(키워드)를 뽑아내는 것이에요.
[^ko]: **ko-sroberta-multitask** — 한국어 문장의 의미를 숫자 목록(벡터)으로 바꿔주는 공개 AI 모델 이름이에요.
[^emb]: **임베딩** — 글의 의미를 숫자 목록(벡터)으로 바꾸는 것이에요. 뜻이 비슷한 글은 비슷한 숫자가 되어서, 컴퓨터가 의미를 비교할 수 있어요.
[^faiss]: **FAISS** — 숫자로 바꾼 데이터 중에서 비슷한 것을 아주 빠르게 찾아주는 검색 도구예요. Meta에서 공개했어요.
[^sim]: **유사도 검색** — 글자가 똑같지 않아도 의미가 비슷한 것을 찾아주는 검색이에요. 예: '딥러닝'을 검색하면 'deep learning' 논문도 나와요.
[^st]: **Streamlit** — 파이썬 코드만으로 웹 화면을 만들 수 있는 도구예요.
[^fill]: **충전율** — 빈칸 없이 값이 채워진 비율이에요. 94.0%라면 100건 중 94건에 키워드가 들어 있다는 뜻이에요.
[^noise]: **노이즈** — 찾고 싶은 정보에 섞여 들어온 쓸모없는 정보예요.
[^datathon]: **데이터톤** — 데이터를 분석하고 모델을 만들어 문제를 푸는 대회예요. 해커톤의 데이터 버전이에요.
