# 의미론적 검색 엔진 모델 구축

**소속 / 기간** 2025 SSU 데이터톤 대회
**최종 성과** 대회 우수상 수상, AI 혁신 지수 리포트 산출
**사용 기술** Python, FAISS (Vector Search), AI Modeling

## 문제
기존 키워드 매칭 기반 검색은 질의어와 문서의 표면적 단어가 일치하지 않으면 관련 문서를 찾지 못하는 한계가 있었습니다. 문맥과 의미가 유사한 문서를 찾아내는 검색 방식이 필요했습니다.

## 나의 역할
데이터 전처리부터 모델링 및 최적화까지 프로젝트 전 과정을 주도적으로 수행했습니다.

## 구현 방법
- Facebook AI Similarity Search(FAISS)를 핵심 벡터 검색 엔진으로 채택
- 텍스트 데이터를 임베딩 벡터로 변환하는 전처리 파이프라인 구축
- 유사도 기반 검색(Semantic Search)이 가능하도록 인덱싱 및 검색 로직 구현

## 문제 해결 과정
단순 키워드 매칭으로는 걸러지지 않는 의미적으로 유사한 문서를 벡터 공간상의 거리로 재정의하여, 검색 정확도를 끌어올리는 방향으로 모델링 방식을 반복 검증했습니다.

## 결과
대회에서 우수상을 수상했으며, AI 혁신 지수 리포트를 통해 성과를 정량적으로 검증받았습니다.
