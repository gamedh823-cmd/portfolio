# ARM 코드 최적화 및 이미지 변환 시스템 구현

**소속 / 기간** 마이크로프로세서 프로젝트
**최종 성과** Subproject#2(음화 변환) 구현 및 메모리 리로케이션 분석 완료
**사용 기술** ARM Assembly, Keil MDK, Embedded System

## 문제
Keil MDK 임베디드 환경에서 32비트 RGBA 이미지 데이터를 어셈블리 레벨에서 직접 처리해야 했고, 개발 중 링커 진입점(entry point)이 충돌하는 문제가 발생했습니다.

## 나의 역할
색 반전(음화 변환) 연산을 수행하는 ARM 어셈블리 함수를 직접 구현하고, 링커 충돌 문제의 원인을 분석해 해결했습니다.

## 구현 방법
- ARM Assembly로 32비트 RGBA 픽셀 데이터를 순회하며 색상 값을 반전시키는 함수 구현
- Keil MDK 환경에서 메모리 리로케이션(주소 배치) 구조를 분석
- 링커 스크립트/진입점 설정을 점검하여 충돌 원인 파악

## 문제 해결 과정
링커 진입점이 충돌해 빌드가 정상적으로 이뤄지지 않는 문제를, 메모리 리로케이션 구조 분석을 통해 원인을 특정하고 진입점 설정을 재조정하여 해결했습니다.

## 결과
Subproject#2(음화 변환) 기능 구현을 완료했고, 메모리 리로케이션 분석 결과를 보고서로 정리했습니다.
