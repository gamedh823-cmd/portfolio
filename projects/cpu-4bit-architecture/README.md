# 4-bit 하드웨어 아키텍처 설계

**소속 / 기간** 컴퓨터구조 프로젝트
**최종 성과** 설계 명세에 따른 동작 검증 완료
**사용 기술** Logic Design, Hardware Architecture

## 문제
시스템 동작의 근간이 되는 하드웨어 레벨의 동작 원리를 이해하기 위해, 4-bit 기반 아키텍처를 요구 명세대로 직접 설계하고 검증할 필요가 있었습니다.

## 나의 역할
4-bit 아키텍처 및 세부 논리 회로를 직접 설계했습니다.

## 구현 방법
- 요구 설계 명세를 기준으로 4-bit 연산 구조와 세부 논리 회로 설계
- 설계한 회로가 명세대로 동작하는지 검증

## 결과
최종 결과보고서를 통해 요구된 설계 명세의 모든 동작이 오차 없이 수행됨을 확인했습니다.

## 증빙 자료
- 별도 보고서/설계서는 현재 로컬 아카이브 상태로, 온라인 링크 미연동입니다.
